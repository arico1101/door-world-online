# トビラ せかい版 オンライン

各自の端末で遊ぶ、教育ボードゲーム「トビラ せかい版」。
Cloudflare Workers + Durable Objects。公開URL https://tobira-online.tobira-online.workers.dev

```bash
npm install
npx wrangler dev        # http://localhost:8787
npm run storybook       # http://localhost:6006（画面を状態別に確認する）
```

## 盤面はふたつ（2026-09-21 に統合）

ロビーで進行役が「どこまで遊ぶ？」を選ぶ。**ゲームの中身は同じで、長さだけが違う。**

| | ぜんぶ（`full`・既定） | みじかめ（`short`） |
| --- | --- | --- |
| 盤面 | 36マス・6章 | 24マス・4章 |
| 年齢 | 6歳 → 35歳 | 6歳 → 25歳 |
| 人数 | 2〜6人 | 1〜4人 |
| 目安 | 60分ぐらい | 25分（ふりかえり抜き） |
| トビラ | 9枚（進学・くらし・まち・技術・しごと・留学・学びなおし・挑戦・大きな夢） | 6枚（進学・くらし・大学・まち・技術・しごと） |
| トビラに必ず止まるか | **止まらない**（サイコロで飛びこされる） | **すべて止まる**（全員が6枚と出会う） |
| AAI | 留学のトビラ（26歳）・カギ★5 | 大学のトビラ（19歳）・カギ★3 |
| 奨学金 | 35歳のゴールで残額を一括清算 | 清算しない（残額を背負って25歳へ） |
| みんなで話すマス | なし | 22歳に1つ |
| 大学院（24歳） | なし（大学のトビラが盤面に無いため） | あり（19歳で大学に行けた人だけ） |
| 助け合いの輪（chiiki） | 挑戦・大きな夢のトビラが受けもつ | まち・くらしのトビラが受けもつ |

「みじかめ」は、もともと **あしなが内部の検証用**に別リポジトリ（`door-world-short`）で作った短縮版。
2026-09-21 にこちらへ統合した。**以後、UIの修正は1か所で済む。**
`door-world-short` は参照用に残してあるが、もう手を入れない。

### モードの足しかた・触りかた

`public/rules.js` の `MODES` にすべてまとまっている。盤面（`SQUARES`/`AGES`/`CHAPTERS`）、
エンディング、人数、しきい、清算するかどうかが1か所に並んでいる。

⚠️ **「いま選ばれているモード」をモジュール変数に置いてはいけない。**
サーバー（Durable Object）は1つの isolate で複数のルームを動かすので、
別のモードのルームが同居する。サーバー側は必ず引数で渡す（`R.mode(g.mode)`）。
画面側は1ゲームしか描かないので、`public/app.js` の `M` に持たせてよい
（状態が届くたびに入れかえている）。

盤面のマス数を変えるときは、`public/app.js` の `LAY_*` も直す。
**1章＝6マスは守ること**（PCは6列、スマホは3列。章ラベルの位置決めがこれに依存している）。
道の折れ線は「Uターンがちょうど半分で切れて、切り口が水平になる」ように
1段目と最終段だけ左へ66のばしてある。段数を変えたらこの値を解き直す
（数値で最適値を出せる。36マス6段でも66でよく、ずれは0.003タイル）。

### キャラ絵について

**キャラは家庭カードで決まる**（2026-10-06〜）。家庭カードを全員に見せるようにしたので、見た目も生まれた場所にそろえた。
`public/rules.js` の `FAM_LOOK`（家庭→系統）と `CHAR_POOL`（系統→キャラ）、`assignChars()` で配る。

| 家庭 | 系統 | キャラ |
| --- | --- | --- |
| w1 欧米 | white | `wb`（男の子・水色）／`wg`（女の子・ピンク） |
| w2 日本・w4 外交官（駐在） | jp | `p1`〜`p4` |
| w3・w5・w6 ウガンダ | black | `bb`（男の子・ティール）／`bg`（女の子・コーラル）、足りないときだけ `bb2`／`bg2` |

- 1ゲームに同じキャラは出ない。ウガンダの家庭は最大3人同時に出るので、黒人の子は**服の色ちがい**
  （`bb2` からし色・`bg2` 黄緑）を用意してあり、3人目にだけ使う。これはコードで服だけ塗りかえたもので、
  別の子の本描きがあれば差しかえたい
- プレイヤーの色（リング・名札）は、キャラの服の色にそろえる（`CHAR_COLOR`）
- w4（外交官としてウガンダに駐在）は「長期休みには帰国する」ので、日本から来た家庭として `jp` にしている。
  変えるなら `FAM_LOOK.w4` の1か所
- `p5`・`p6` はロビー（配る前）の仮の絵としてだけ残っている。ゲーム中には出ない

画像の作り方（そろえ方）：
- `-face.png` は 160×160。よろこびの絵から、頭と肩を正方形で切り出す
- ほかの4枚は 260×340。**足が y=334 に接地**、表情どうしで体の大きさが変わらないよう**4枚とも同じ倍率**で縮める
  （`preserveAspectRatio="xMidYMax"` で描くので、ここがずれると人によって大きさが違って見える）
- 生成画像は1枚ごとにキャラの描かれた大きさが違うので、**1枚ずつ**「頭のてっぺん〜足 ＝ 238px」に合わせる。頭のてっぺんは効果線（左右に出る）を避けて、体の中心の細い帯で測る
- 生成画像には、ほぼ透明のもや（α≦32）が端まで残っていることがある。測る前に消す
- `bg-sad` だけは元絵が黒地で、背景を切り抜いてある（黒いズボンも背景と一緒に消えたので、同じ子の立ち姿の足の形を型にして元絵から戻した）。頭のまわりにうっすら光のふちが残る。透明背景の元絵があれば差しかえたい

## 守るべき条件

1. **ウガンダで生まれた遺児家庭（w5/w6）が必ずゲームに入る**
2. **AAIのトビラを盤面から落とさない**
3. **種明かしを守る。** 家庭カードの**「とくい」（`perk`/`perkText`）と見えない選択肢のタグ（`hide`）は本人の接続にだけ**／
   選択肢とその状態も手番の人にだけ／`pnote`・`pnotes` は本人だけ／👁？？？の種明かしは結果発表まで伏せる。
   家庭カードの**境遇**（名前・物語・朝・1日の暮らし）は、2026-10-05 から**配られた時点で全員に見せる**
   （`src/index.js` の `publicCard()`）。比較こそが学びの本体で、隠していると話し合いが萎縮していたため。
   `publicCard()` に `perk`・`perkText`・`hide` を足すと種明かしがこわれる（`test/ops.mjs` で確かめている）
4. **新しいテキストは必ず日英そろえる**（`{ja, en}` ＋ `L()`）
5. **デザインは変えない**（Zen Maru Gothic ／ パステル ／ 手描き風のSVGアイコン）
6. **1章＝6マス**

## テスト

`npx wrangler dev` を起動したうえで：

```bash
for n in 2 4 6; do MODE=full N=$n node test/play.mjs; done
for n in 1 4; do MODE=short N=$n node test/play.mjs; done
node test/ops.mjs && node test/full.mjs && node test/short.mjs
node storybook/validate.mjs
```

## デプロイ

`main` に入った変更は GitHub Actions が公開URLへ自動反映する。
PRを立てるとPRごとのプレビューURLが出る（Durable Objects を使うため、
Cloudflare の Version Preview URL ではなくPRごとの独立した Worker としてデプロイしている）。

いずれも次の2つのシークレットがリポジトリに必要：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`。
手で出すときは `npx wrangler deploy`。
